How this works
Rotation. Stand-by runs Monday–Sunday and rotates through the team in list order. Enter names below (one per line) and pick the date the list takes effect — it applies from the first Monday on or after that date, and the schedule from there forward is rebuilt automatically; earlier weeks are untouched. To add or remove someone mid-year, edit the list and apply it with a new effective date.
Swaps. With no marker selected, click any cell to reassign stand-by — for that single day or the whole week. Swap a stretch of days by setting each day individually. "Auto" puts a day or week back on rotation; reassigning a whole week clears any day swaps inside it.
Leave / Family day / Misc. Pick a marker in the toolbar, then click or drag across a person's days. Use the eraser to clear. The blue marker can be renamed to whatever you track.
Holidays. Paste the holiday memo text — dates like "Monday, February 16 — Washington's Birthday" are picked out automatically and shade the whole column.
Sharing (SharePoint). Sync the SharePoint document library to your PC with OneDrive, then click Data file → Create shared file and save standby-data.json into that synced folder. Everyone else opens their copy of this page and does Data file → Open shared file once, pointing at the same JSON. Edits save to the file automatically a moment after you make them, and the page picks up other people's saves about every half minute. If two people save at nearly the same time, the second saver is warned and chooses which version wins. Needs Edge or Chrome. Browsers usually re-ask permission per session — click the yellow "reconnect" notice in the header when it appears.
Backups. Without a connected data file, everything stays in this browser only. Export/Import always work as manual backup either way.
